# makefun-worst-superpower

A program that writes one original one-liner to `/output/entry.txt` — the
whole entry for the make.fun competition **"Worst Superpower"**
(`u-suroto-worst-superpower-461dcdbe`).

## The superpower

> I can talk to fish — but only the ones already on ice at the supermarket, and all they want to talk about is being eaten.

121 characters. Talking to fish would be a fine power, except the only
fish it works on are dead, on ice, in a supermarket — and the one
conversation the power enables is a trout monologuing about being eaten.
Useless twice over, and easy to picture: a hero leaning over the fish
counter, nodding along politely.

## Run it

```sh
node main.ts
```

Writes `entry.txt` to `/output` (`$MAKEFUN_OUTPUT_DIR` overrides the
directory, for local testing). Node 22, standard library only.
